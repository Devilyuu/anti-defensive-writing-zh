# 防御填充与必要边界：分类、判别与改法

“拆防御”一步拿不准时读。防御性写作指作者或模型为了预先回避质疑而写出的、不给读者新信息的文字：无对象的自贬、重复免责、层层对冲、虚设反方、流程自述、安抚。它让中心判断被限定语、平衡句和免责声明遮住。反面不是“删掉所有限定”：必要边界（范围、条件、风险、未验证事项）是读者正确使用结论所需的信息，删了就是失真。

**对冲悖论**：语料和 Wikipedia 的观察都指向同一点，AI 文本的问题不是句内限定词多，而是不绑定具体主张的元层级免责（“仅供参考”“可能不够全面”）多，同时回避句内具体限定（“在两个数据集上”“样本来自单一学校”）。一刀切删限定词会让文本更像 AI，也会把量化改成全称、把推测改成断言。

## 一、判别法

按顺序问，任何一问得出“读者会少知道什么”就不能删，只能写准。

1. **删除检验**：这句删掉后，读者少知道了什么？少了事实、范围、立场、后果、下一步中的任何一项，就保留并写准。什么都没少，就是填充。
2. **功能检验**：这句话是在帮读者正确使用结论，还是在替反方论证、压低本文价值？前者留，后者删。按句子在当前位置的作用判断，不按词表。“可能”“在一定程度上”本身没有对错。
3. **五判据**：省略后是否影响读者判断“观点是否成立”“如何理解证据”“结论的适用范围”“研究设计是什么”“能否正确使用这个结果”。任一成立就保留。
4. **来源检验**：来源标记型限定（“据教务处通知”“依照 2026 年 9 月官网页面”“我没查最新数据，以官网为准”）保留；立场回避型限定（“在一定程度上”“某种意义上”“或许”叠三个且没有对象）删。
5. **删读测试**：堆叠的限定词逐个删掉试读，读者判断不变的删，改变时间、范围、否定、推测、程度的留。真不确定留一层，确定的事零层。
6. **位置检验**：同一条限制写一次，放在读者需要它的位置。它在摘要、段首、结论里是高影响位置，省略会误导就留在当地；在局限一节里是正常位置。不把所有限定都挪到局限章节，也不在每段重复。
7. **信息强度分层**：每个主张标一下它属于哪一层，用对应的措辞：材料直接显示的（“图书角一个月登记了 143 次借阅”）；由材料合理推出的（“借阅集中在午休，所以午休时段开放最要紧”）；待验证的（“其他班是否同样适用尚未试过”）；必要边界（“本文只讨论班级图书角，不涉及学校图书馆”）。防御填充是不属于任何一层、只表达“我可能不够好”的句子。

## 二、分类表

| 类型 | 中文形态（例） | 处理 |
|---|---|---|
| **删：无对象的自贬** | “仍有许多不足”“水平有限”“抛砖引玉”“不足之处敬请指正”“仅供参考”“具有一定参考价值”“只是一个小小的尝试” | 删。真实限制改写成具体范围（见第三节） |
| **删：重复免责** | 每段结尾都来一句“以上仅为个人观点”；同一条限制在摘要、引言、结论各说一遍 | 写一次，放在对应位置 |
| **删：虚设反方再否定** | “需要说明的是，本文并非否认传统方法的价值”“当然，这并不是说……”“笔者并不认为……”连续出现，而文中没人提出这些质疑 | 删防御；如果里面藏着真实主张，直说主张。读者会真正权衡的选项和文中有出处的反对意见保留 |
| **删：立场真空** | “各有优缺点”“因人而异”“取决于多方面因素”“见仁见智”“既带来了机遇，也带来了挑战”“机遇与挑战并存”“需要理性看待”“辩证看待” | 几乎永远成立，等于没有判断。有具体选择条件就写条件，作者有判断就写判断（“备课省了时间，但生成的案例和本地企业对不上，这是我们试点里最大的问题”）；没有就删 |
| **删：假平衡** | “一方面能提高备课效率，另一方面也对教师数字素养提出了更高要求”两边都不具体；两件没有对立关系的事硬排成“一方面……另一方面”；“既要……也要……”不说怎么做 | 两边都落到材料，或只写有依据的那一边；两件事没有对立就分开说 |
| **删：堆叠限定** | “可能在一定程度上潜在地对……产生某种程度的影响” | 多层限定通常是修补先前夸张留下的，不是报告真实怀疑。收成一层，说明不确定性来自哪里 |
| **删：装坦诚** | “说句实话”“我必须诚实地说”“缺点也说一句，免得你们说我恰饭” | 姿态删，自曝的缺点是真信息必须留 |
| **删：知识截止与资料有限免责** | “截至我的知识”“目前公开资料有限，推测其……”“关于 X 的信息不多” | 整句删；承认没资料之后不能再用猜测填空。需要时效说明就写带日期的来源 |
| **删：流程自述与自我保证** | “本文由 AI 整理”“未经核实处已标注”“我们尽力确保准确”“已保留原意，未改动事实” | 删。只保留改变读者下一步行动的提醒（“两家场馆未公布团体票价，需电话确认”） |
| **删：安抚与方向认证** | “你已经走在正确的路上”“完全不用担心”“这是一个很好的开始” | 只能删或改成“现有信息不足以判断”，不能降格成“问题不大”继续替读者下结论 |
| **删：先认不重要再拔高** | “虽然这只是初步探索，但它意义重大” | 先设一场没人要求的比赛再解释为何没输。删前半，后半按材料写 |
| **删：没人问的问题** | 在文中回答一个没有读者会提出的质疑；为没有要求的责任辩解 | 删 |
| **留：范围声明** | “本文只讨论课后作业”“在已测试的两个数据集上”“样本为 2024 级两个班” | 留，写在相关主张旁 |
| **留：研究设计与方法局限** | “样本来自单一学校”“未做消融实验，还不能认定提升来自模块 A” | 留。说清哪句话因此缺少依据，不笼统写“实验不充分” |
| **留：承担论证的概念区分** | “这不是退款，而是撤销尚未结算的授权”“问题不在算法，而在数据标注” | “不是…而是”在这里是真实区分，留 |
| **留：基于证据的必要限定** | “跨域效果尚未评估”“这一结论只在 batch size 小于 64 时成立” | 留，靠近对应结果 |
| **留：安全、法律、学术规范说明** | “孕妇请遵医嘱”“退款以发卡银行处理时间为准”“本研究经伦理委员会批准”“利益冲突声明” | 留，只调前后衔接，不调意思 |
| **留：请求里的真实让步** | “如果周五不方便，请告诉我”“企业那边有考核要求的话，我们再商量” | 去掉卑微的说法（“不行也完全没关系”“真的很抱歉”），保留它的信息；整句删掉会把请求改成硬要求 |
| **留：真实更正** | “上一版本把日期写错了，此处更正” | 留 |
| **留：来源标记** | “据教务处 9 月通知”“依照场馆官网 8 月的公告” | 留 |
| **留：真实的未完成与犹豫** | “延迟和错误率还没测出来，先继续观察”“说实话我自己也没把握能不能推广”（作者本人写的） | 留。不替作者变得更自信 |
| **留：文种要求的说明** | 论文的 limitations 一节；工作总结里的“存在的问题”；期刊要求的“本文结构如下” | 留，但要写具体问题，不写“仍有差距” |
| **留：时间、资料、统计范围说明** | “截至 2026 年 9 月”“数据来自 2024 至 2025 两个学年” | 留 |

## 三、改法：不只是删

- **正向范围**：把“不研究什么”写成“研究了什么”。“我们并不认为这些案例能够代表所有城市治理情境”→“本文分析了〔年份〕至〔年份〕的〔对象〕城市治理案例。”
- **说明不确定性来自哪里**：“这或许可能在一定程度上说明……”→“现有证据支持这一解释，但尚不能据此估计总体效应。”
- **条件句加断言**：把边界写清再下判断。“某种程度上可以认为效果不错”→“在〔条件〕下，〔指标〕从〔值〕提高到〔值〕。”
- **用带日期的来源替代免责语**：“以上开放时间仅供参考”→“以上开放时间来自场馆官网 8 月的公告，出发前以官网当天公告为准。”
- **把约束写成可行性**：事实不变、方向翻转的合法改法。“本方法仅在单卡上运行”→“本方法单卡即可运行。”前提是材料确实如此，且没有隐去“多卡未测”这类读者需要的信息。
- **优势要明说**：反防御的正面一半。有证据支持的优势写出在什么条件下成立、为什么会出现、解决了什么实际问题，不指望读者从表格里自己发现。
- **不用新套话填旧套话**：删掉“具有重要意义”后不补“具有里程碑意义”；删掉“仍有不足”后不补“未来可期”。
- **无材料时说明只能形成什么层次的判断**：“材料只支持‘在两个班有效’这一层判断，推广到年级需要再测。”

## 四、论文里的不利结果

1. 会影响核心结论的不利结果必须保留。区分“与主张无关的结果”和“对主张不利的结果”：前者可以不进主线，后者可能要求修改主张。
2. 证据只支持部分情况就缩小范围；完全不支持就撤回结论。
3. 说清哪个指标升、哪个指标降，两个数字都写。材料是“准确率 90% 降到 89%，延迟 100 ms 降到 60 ms”时，写“该方法将延迟从 100 ms 降至 60 ms，准确率为 89%，基线为 90%”，不写“准确率略有下降，说明方法仍存在一定局限”，也不换一个更好看的指标当主战场。
4. 不把一个指标落后写成整个方法有问题，也不把局部现象写成对整体方法的否定；负面判断不宽于证据。
5. 原因不明就不编造解释。“这可能是因为模型容量不足”是作者的推测，不能改成“该现象与模型容量相关”这种去掉推测标记的断言。
6. 事后发现的有利子集不能伪装成预先确定的优势；不得把相对百分比写成百分点，不得把观测到的关系升级为因果。
7. 少做了一个实验，先说清哪句话因此缺少依据，不笼统写“实验不充分”。

## 五、模型输出里的过度免责

Wikipedia 把“值得注意的是……可能因情况而异”列为 2023 年前后模型的典型痕迹，并指出 GPT-4 系统卡把这类句子当作“部分拒答”的例子：它不是作者的判断，是模型在回避。处理顺序：

1. 先看它有没有绑定具体主张。绑定了（“这个价格截至 9 月”）就写准；悬空的（“以上仅供参考”）删。
2. 含真实时效或范围信息的，改成带日期的来源或具体范围，不直接删。
3. 安抚句只能删或改成“现有信息不足以判断”。
4. 删掉描述自身工作过程的声明（“本文由……整理”“已标注未核实处”“我们尽力确保”），只留改变读者行动的提醒。
5. 协作对话、调试过程、占位策略（“[在此插入]”）不进对外文本。

## 六、对称防线：不替作者变得更自信

拆防御最常见的失误是删过头。下面这些是失真，不是去 AI 味：

- “多数学生在第二周完成”改成“学生在第二周完成”。
- “可能提升”改成“提升”；“这可能是因为”改成“这是因为”。
- “质的跃迁”改成“变化”；“我反对”改成“我持保留态度”。
- “还没测出来，先观察”改成“效果良好”。
- 把所有“可能”统一改成确定表达；把作者真实的强烈评价降成温吞。
- 删掉“跨域效果尚未评估”，因为它“看起来谨慎”。

改完自问三条：有没有删掉影响结论成立的事实？有没有新增原文没有的主张？有没有超过这处问题需要的最小改动？

## 七、只诊断时的输出格式

每条：位置、原句片段（一字不改，不超过 20 字）、用平常话说的问题（第二节的分类名只供你判断，不写给用户）、改法方向，必要时一句话说明这样改对读者判断的影响。未发现就直接说明未发现，不为凑数而改。结构性建议（整段该不该存在）单列，不混进逐句诊断。
