# 中文 AI 痕迹候选信号表

长文、深改、只诊断时读。这是一张**候选信号表，不是禁词表**。每一行都写了保留条件，因为同类工具最常见的失误不是漏删，而是把承担逻辑、属于作者习惯或文体规范的句子当成 AI 味删掉。

## 先读这八条

1. **成因**：语言模型按“最可能的下一句”为所有读者写，于是处处是默认选择：整齐、抽象、对称、收束。真人作者为一个读者选材，用词不均匀而具体。表里的每一行都是“默认选择”的一种形态。
2. **这些是问题的信号，不是问题本身**。Wikipedia《Signs of AI writing》的原话是 descriptive not prescriptive：只把表面词换掉，深层问题（没内容、没对象、没判断）还在，而且更难被发现。我们的目标是读者看懂、相信，不是躲检测。
3. **单个特征不是证据**。一两处是巧合，密度和共现才是信号；某词被滥用，不代表它的同义词也被滥用。词汇层最脆弱，年内就漂移（“值得注意的是”在英文已归入历史指标，中文仍高频；破折号正在被新模型抑制），结构层最稳。所以先看结构，再看词。
4. **两级阈值**：标“强”的见一处就看；标“弱”的成片出现才处理，单独出现不动。
5. **不作为改写理由**（有语料实测，人写的文章同样常见或更多）：句内同构排比、正文设问与问句小标题、比喻本身、段落长短或句子长短是否均匀、被动句、名词化本身、正文里单次出现的“首先……其次”、反复写全称、单字虚词偏少、工整、非母语式的正式感、短文本。句长整齐本身不是信号，相邻几句共用一个骨架才是（见 C 层“相邻句同一骨架”）；连接词也一样，单用不算，一段里多数句子都靠它起头才算。Wikipedia 还把 very、perhaps、tends to 这类句内微量限定列为**人类**信号：AI 的问题不是限定词多，而是不绑定具体主张的元层级免责，同时回避句内的具体限定。一刀切删限定词会让文本更像 AI，也会失真。
6. **文体规范优先**：公文的“进一步”“切实”、期刊要求的“本文结构如下”、教学任务书的分点、法律条款的免责、FAQ 的问句段首，在该文体里是规范，不按本表处理。
7. **作者样本优先**：用户旧稿里一贯出现的破折号、反问、排比、冒号，按样本频率保留。
8. **模型差异**：同一特征在不同模型上量级差很大。本 skill 跑在 Claude 上，揭晓式破折号和提示性冒号是 Claude 偏重项，值得多看一眼；但判断仍按触发条件逐句认，不按“某个模型的味”套。

## A. 内容层（表面修改掩盖不了）

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 拔高意义：“具有重要意义”“具有重要的理论价值和实践意义”“影响深远”“里程碑式的”“为……奠定了基础” | 宣布重要，不说重要在哪 | 能换成具体对象和后果就换；换不出就删，不编数字。历史事件的公认评价（“载人登月的里程碑”）不动 | 强 |
| 机械拔高与段末升华：“为……提供有力支撑／保障”“助力……高质量发展”“为……贡献力量”“注入新动能”“进一步提升人才培养质量”；几段都用这类句子收尾 | 每段都要往大处收一下，收尾句和本段材料无关 | 删收尾句，段落停在具体结果或冷结论上；课题申报和公文里要写成具体产出和检验方式（“形成 3 份课程标准，下学期在 2 个班试用”），写不出就删。政策文件原文里的提法照引 | 强 |
| 万能正确话：“应结合实际情况”“因地制宜”“不断优化完善”“积极拥抱变化”“以适应新时代……的需要”“多措并举” | 无法反驳，也没有信息 | 删除检验：删掉后读者什么都没少，就删；有具体做法就写做法（“每月抽两节课录像，教研组一起看”） | 强 |
| 先认不重要再拔高：“虽然只是一个小小的尝试，但它意味着……” | 先设一场没人要求的比赛，再解释为何值得 | 删前半，后半按材料写 | 强 |
| 空泛判断不带对象：“效果明显”“体验很好”“值得推荐” | 评价词后面没有场景、对象、结果 | 材料里有就补对象，没有就删句或保留概括 | 强 |
| 假主体 / 无生命施动者：“数据告诉我们”“系统赋能教师”“课程培养了创新思维”“时代呼唤”“决定应运而生” | 让抽象名词做人的动作，回避“谁做了什么” | 问“谁做了什么”：有主体就写出来；原文没有主体时不要猜 | 强 |
| 模糊归因：“有研究表明”“根据相关研究”“国内外学者普遍认为”“大量实践证明”“有数据显示”“专家认为”“用户反馈显示”“很多人说” | 用匿名权威替代证据 | 有来源用用户给的；没有就改成作者自己的判断并写明范围，或保留原句标“〔需查证来源〕”交作者。不能只删“研究表明”让论断变成裸事实，也不能替作者补一个来源 | 强 |
| 伪统计与伪共识：“超过 80% 的教师已经开始使用”“99% 的人不知道”“很多姐妹都说”“据统计大多数” | 无来源的数字和共识 | 用户给了来源就写来源；没有就删，或标“〔需查证来源〕”并在说明里提醒。改成作者真实观察（“我问过的两位同事”）只在材料支持时做 | 强 |
| 模糊关联：“与……有关”“在……的推动下”“伴随着……” | 用含糊关系躲开因果判断 | 说得清就直说关系；说不清就保留模糊，不升级为因果 | 弱 |
| 提纲式收尾与过度中性：“挑战与展望”“未来可期”“仍需进一步研究”“这一现象值得关注”“值得深思”“有待进一步探讨” | 用展望或“值得关注”代替结论，看似稳妥，实际没有观点 | 有具体下一步或具体待研究的问题就写出来；没有就删 | 弱 |
| 装饰性假细节：“凌晨三点”“第三杯咖啡已经凉了”“窗外下着雨” | 氛围细节比套话更像 AI，而且多半是编的 | 作者材料里有的留，没有的删 | 强 |
| 内容债：整段没有观点、没有证据、没有对象；“正确但没用”（“教师应积极提高数字素养，以适应新时代需要”）；只有判断，没有人、时间、地点、动作、数据 | 这不是语言问题，改写解决不了 | 删除检验：删掉这一段，读者会不会少知道任何具体信息？不会就删或压成一句。细节只用作者材料补；没有就在说明里列出最值得补的一两处（哪个班、用了什么、结果如何），不替作者编场景和立场 | 强 |

## C. 句式与词汇层

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 翻案腔：“不是 X，而是 Y”“X 不是 A，是 B”“真正重要的不是 X，而是 Y”“与其说…不如说”“看似…实则”“你以为…其实”“问题不在 X，而在 Y”“不仅…更是” | 制造一个没人持有的 X 再推翻，显得有洞见 | X 是真实存在的误解或真实区分、读者会因此做不同的事时保留（“这不是退款，而是撤销授权”“这次交的不是成品，而是过程记录”）。虚设的 X 删掉，直接写 Y；Y 若也只是抽象判断（“不仅是考验，更是契机”），整句删。不要换成“A 固然…但 B”，也不要把同一层拔高换成口语再说一遍（“当场考的是应变，过后也是反思的机会”仍是同一句空话） | 强 |
| 相邻句同一骨架：“它不只是……它更是……它甚至……”；“首先，应……，提升……。其次，应……，提升……。此外，还应……，实现……。” | 排比撑篇幅；连接词＋应＋动作＋目的连用三次 | 换成推进关系（因果、时间、场景），不是换词；没有材料的“提升……”“实现……”尾巴删掉。句内三项并列不算 | 强 |
| 转变排比：“实现从 A 到 B、从 C 到 D、从 E 到 F 的转变”；连续几句“——从 A 转向 B” | 三件套式的“转变”，项项等长，多半没有材料 | 有材料的那一项展开说（做了什么、哪个班、结果如何），其余删 | 强 |
| 目的链长句：“通过……，不仅能够……，还能够……，从而进一步提升……，为……提供有力保障” | 一句话串起手段、两个收益、升华和保障，每一环都没有对象 | 拆成做了什么、结果是什么；没有材料的“从而……为……”尾巴删掉 | 强 |
| 抽象词堆叠：一句里四个以上“构建、多元、协同、生态、推动、创新、赋能、提升、融合、体系”（“构建多元协同育人新生态，推动教育教学模式创新，赋能人才培养质量提升”） | 名词多、动作少、对象少，没有语病但没有信息 | 问清谁对什么做了什么；材料里有就写成动作和结果，没有就删句。单个词不算，课题名称和政策原文里的提法照引 | 强 |
| 段首零主语评论：非首段以“值得注意的是”“更重要的是”“关键在于”“问题在于”“说白了”“这意味着”“不难看出”开头，且整句没有“这/那/其/此”回指上文 | 评论壳悬空，和上文没有连接 | 多数情况加一个“这”字就够；没有信息的壳删掉 | 强 |
| 四字动宾连排：“突破了传统范式，填补了理论空白，创新了分析视角，丰富了研究方法” | 整齐而无证据 | 只保留有材料支撑的一项展开说；并列项篇幅与重要性成正比 | 强 |
| 抬升词 / 重锤句：“本质上”“归根结底”“说到底”“真正重要的是”“底层逻辑”“认知”“格局”“颗粒度”“松弛感” | 抽象抬升的小机关，替代论证 | 承担作者判断且有下文支撑的留；只做抬升的删 | 弱 |
| 名词化搭子：“进行/实现/做出/采取/加以/给予/起到/发挥/形成 + 名词”（“对流程进行了优化”） | 动作被包成名词，主体和结果都虚了 | 改回一个动词（“优化了流程”）。公文和法律文本中的固定搭配不动 | 弱 |
| 回避简单动词：“发挥着重要作用”“承载着使命”“扮演着角色”“作为……的载体”“展现出活力” | 用长搭配替代“是/有/做了” | 改成“是”“有”“做了”“减少了”，材料允许时写出具体结果 | 弱 |
| 同义词轮换：“系统/平台/工具/方案”轮着指同一个东西；“教师/老师/教育工作者” | 为避免重复而换词，读者要重新对应 | 用最准确的名词反复称呼。公文允许必要重复 | 弱 |
| 抽象主语：“时代/科技/行业/未来/历史 + 动词” | 宏大其实是逃避交代谁干的 | 有责任主体就写出来；没有就保留原状或标注 | 弱 |
| 远距离叙述者：全文主语是“人们/大家/我们/用户/读者” | 没有一个具体的人 | 材料里有具体对象就写；教学材料用“你们” | 弱 |
| 翻译腔五种：过长前置定语、“当……时”、前置话题壳（“对于……来说”“就……而言”）、句首连接词堆叠、“这意味着”复述 | 直译结构 | 保持原语体改成中文语序，不用口语词替换（“然而”不是“其实”） | 弱 |
| “的”字定语超过两层 | 一口气读不完 | 拆句 | 弱 |
| 文学化膨胀：小事膨胀成“真理/宿命/底色/命脉”；“每段结尾升华” | 把体验写成格言 | 允许一段只讲事；一篇最多留一两处作者真正的判断 | 弱 |
| 拟人化喻体：“像一位智慧的导师”“像一座灯塔” | 比喻库存（双刃剑、桥梁、灯塔、引擎、基石、催化剂、马拉松、钥匙、天花板） | 具体人喻体（“像一个老师傅”）不动；库存喻体删或换材料 | 弱 |
| 伪口语垫词：“说到这里”“更重要的是”“回过头来看”“那么问题来了” | 口播腔替代逻辑连接 | 用事实间的真实关系承担过渡 | 弱 |
| 连接词连用：一段里多数句子以“首先／其次／此外／与此同时／因此／具体而言／在此基础上／一方面”起头 | 把每一层逻辑都显性标出来，读着像念提纲 | 删掉既不带信息、也不带真实因果转折的连接词，让事情自己排先后；操作步骤（“先打开……再……最后……”）和任务书分点不算 | 弱 |
| 高频抽象词：赋能、助力、构建、打造、推动、促进、深化、强化、完善、融合、协同、多维、多元、全方位、系统化、精准化、智能化、高质量、新路径、新模式、新范式、新生态、闭环、抓手、引擎、底座、体系 | 单个词不说明问题，密集出现才是 | 一句里四个以上按“抽象词堆叠”处理；零散出现的换成具体动作或删。公文、课题名称、政策原文里的规范用语不动 | 弱 |
| 兜底列举：“包括但不限于”“等多个方面”“等等” | 合同和需求文档的写法搬进了文章 | 文章里列出真正要说的几项即可；合同、需求文档、制度条款里保留 | 弱 |
| 括号补充过密：一段里三处以上“（包括……）”“（以下简称……）”“（含……）” | 每句都在补充解释，信息组织机械 | 术语首次出现的全称或缩写说明保留；其余提成独立一句，或删掉读者不需要的补充 | 弱 |

## D. 篇章与段落层

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 默认形状“定义 → 拆项 → 拔高”；读者能预测下一节 | 篇章级模板 | 结构从材料长出来：按问题、时间、因果或场景推进 | 强 |
| 每段同样的“背景—观点—总结”；每节同一种收束句 | 段落级同构 | 只删重复前文的总结句；删后用具体场景、冷结论或真实的开放问题收，不用“这意味着”升华 | 强 |
| 时代套话开场：“在当今……的时代”“随着……的快速发展”“在……的大背景下” | 从宏大背景起笔，推迟进入问题 | 直接从问题、场景或判断开始 | 强 |
| 结构预告与元评论：“下文将从三个方面”“接下来我们看看”“本节介绍”“综上所述”“总而言之” | 聊天机器人式导航 | 期刊要求的结构说明、长报告的导读保留；只重复前文的总结句删 | 强 |
| 命题式小标题 + 首句复述标题 | 标题和正文说同一句话 | 标题用主题名词短语，正文从具体材料进入 | 弱 |
| 小标题对仗：“一、明确目标，找准方向”“二、优化内容，夯实基础”“三、创新方法，提升实效”，四字＋四字或动宾＋动宾连用 | 模板化标题，读者看不出每节讲什么 | 公文、讲话稿里常用，按文体判断；论文、工作总结、公众号改成说清内容的短语（“公开课与听课”“两项校级课题”）。总结的固定结构（成绩、问题、计划）保留 | 弱 |
| 标题堆大词：“数智融合背景下人工智能赋能中职课程高质量发展的实践探索与路径研究”，背景词＋抽象概念＋“路径研究”叠在一起 | 题目看不出研究对象和问题 | 写出研究对象、问题和范围（“中职电子商务等 3 个专业用 AI 生成实训案例的试用研究”）；申报指南要求的政策关键词留一个 | 弱 |
| 标签式冒号行：“核心问题：……”“解决路径：……”“实施方式：……”连续三行 | PPT 和表格的写法搬进了文章 | PPT、表格、提纲里保留；文章和讲稿里改成完整句子，写清谁、做什么 | 弱 |
| 编号枚举撑全文；即使没有列表符号，节奏上仍像念目录 | 用列表代替推进 | 换成时间、因果、场景三种推进；教学任务书、公文的分点是功能性的，不动 | 弱 |
| 段落等厚；中段塌陷（开头结尾用力，中间空） | 为工整而均分篇幅 | 篇幅跟内容走 | 弱 |
| 学术段位套路：“依据/基于 XX 理论”起笔、“此案例印证了/这提示我们”段末、“该处理体现了”分析腔、理论起笔后再进入问题 | 中文论文八股 | 现象、对象或具体问题先行；案例段末只写材料支持的结论 | 弱 |
| Diff 叙述：文档写“新增了……用于替代旧方案”“本次修改保留了……” | 面向改动历史，不面向当前读者 | 改成面向当前读者的说明；版本说明文体除外 | 弱 |

## E. 对话壳与元话语层

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 聊天开场结尾：“当然可以”“以下是”“希望对你有帮助”“如果还有问题欢迎告诉我”“祝好” | 对话残留 | 删。邮件的真实问候与署名除外 | 强 |
| 知识截止与资料有限免责：“截至我的知识”“目前公开资料有限”“关于 X 的资料不多，推测其……” | Wikipedia 判定“包括‘未记载’本身在内全是推测”；承认没资料后再猜更糟 | 删整句；需要时效说明就写带日期的来源 | 强 |
| 说教式提醒：“值得注意的是……可能因情况而异”“需要指出的是” | Wikipedia 把它列为 2023 年前后模型的典型痕迹，GPT-4 系统卡把这类句子当作“部分拒答”的例子；它不是作者判断 | 限定具体主张的留并写准；悬空的删 | 强 |
| 流程自述与自我保证：“本文由 AI 整理”“未经核实处已标注”“我们尽力确保准确”“已保留原意”“未改动任何事实” | 人写的交付不会说自己没犯什么错 | 删；只保留改变读者下一步行动的提醒（“两家场馆未公布团体票价，需电话确认”） | 强 |
| 安抚与方向认证：“你已经走在正确的路上”“完全不用担心”“这是一个很好的开始” | 替读者下结论的空话 | 只能删或改成“现有信息不足以判断”，不降格成“问题不大” | 强 |
| 身份认证式夸奖：“你这个问题问得很好”“作为一位有经验的老师，你一定……” | 对读者的恭维壳 | 删 | 强 |
| 罐头同理心：“我懂”“这确实很不容易”“造成不便敬请谅解” | 空泛安抚 | 真需要安抚时用具体的解决动作；空泛道歉只在真的造成不便时用一次 | 弱 |
| 装坦诚 / 假坦白钩子：“说句实话”“我必须诚实地说”“缺点也说一句，免得你们说我恰饭” | 姿态层 | 姿态删，自曝的缺点是真信息必须留 | 强 |
| 推理链与提示词泄漏：“让我想想”“第一步：”“作为一个语言模型”“根据你的要求” | 工程残留 | 删 | 强 |
| 占位符模板：“[在此插入数据]”“XX 公司” | 未填的模板 | 用户要可填稿时用“〔需作者补充：…〕”统一格式；否则是缺口，报给用户 | 强 |

## F. 排版与符号层

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 揭晓式破折号：句末甩一个短语——像这样 | Claude 偏重项；替代了句内逻辑 | 承担解释、插入、声音延长的破折号是中文规范用法；按作者样本频率；成片才处理，不全删 | 弱 |
| 破折号形式错误：单个“—”、英文短横“–”、“--”或两侧带空格的“ - ”代替“——” | 英文排版习惯移植，复制模型输出时最常见 | 排版错误，见到就改：中文破折号统一为“——”，或按语义改成逗号、冒号；数字范围用“～”或“至” | 强 |
| 提示性冒号与空转句引列表：“重点来了：”“结论是：”“具体如下：”后接列表 | 提示语本身没有信息 | 总说分说的冒号是 GB/T 15834 认可的规范用法，不动；提示语无信息则删；承接上文的只换标点 | 弱 |
| 顿号三连罗列过密 | 列举代替说明 | 成片才处理；并列项篇幅与重要性成正比 | 弱 |
| 中文句子里的半角标点：英文逗号、冒号、分号、问号，英文括号“(含……)”；全角标点旁多余的空格（“（AIGC） 技术”“好的， 下面”） | 复制模型输出时留下的排版残留 | 排版错误，见到就改，不算改动作者语气。网址、时间“14:00”、代码、英文原文里的半角符号不动 | 强 |
| 引号风格混用：同一篇里既有“”又有 "" 或「」 | 没经过人工统一 | 排版错误：大陆简体统一用“”，引号里再引用用‘’；作者或刊物明确用「」的按其规定统一 | 强 |
| 中英文之间空格不一致；品牌大小写不一致 | 排版卫生 | 全篇统一一种；原文一贯的写法（“2026 年”带空格）照原样 | 弱 |
| 加粗泛滥、行内“**标题：**说明”式列表、标题层级跳级、首行重复标题、分隔线 | Markdown 输出习惯 | 要贴到微信、Word、邮件的稿子要清；正文加粗每节不超过一两处 | 弱 |
| 小表格硬凑：两三条内容做成表格 | 为结构化而结构化 | 对比维度多且数据密集时才用表格 | 弱 |
| Emoji 模板：列表每行末尾等距 emoji、每段一个 | 平台模板 | 作者样本和平台要求决定；不全删 | 弱 |
| Markdown 残骸：`**`、`#`、`---`、行首 `>`、行首 `-`、反引号、`[文字](网址)` 漏进要贴到微信、Word、邮件的稿子 | 渠道不匹配 | 清掉；列表改成“1. 2.”或完整句子，链接改成文字加网址 | 强 |
| 引用残片：“【85†L261-269】”“citeturn0search1”“utm_source=chatgpt.com” | 平台引用标记泄漏 | 清掉；链接去掉跟踪参数 | 强 |

## G. 引用与事实层

| 形态（例） | 为什么可疑 | 保留条件 / 改法 | 强弱 |
|---|---|---|---|
| 编造数字、人物、案例、假设性场景：“比如有一次……”“某团队跟我们聊过” | 用虚构具体冒充经历 | 删；教学案例若是模拟要标明 | 强 |
| 补写承诺与条款解读：“随时可退”“无隐藏费用”“每天节省一小时”；把条款“白话解读”成更宽松的意思 | 以作者名义发布假承诺；加判断也算捏造 | 删；条款逐字 | 强 |
| 引文、DOI、页码对不上；参考文献列了没引用；死链 | 幻觉引用 | 原句保留并标“〔需查证来源〕”，不删不改不换 | 强 |
| 格式“异常完美”的参考文献：模型起草的稿子里，条目格式完全符合 GB/T 7714，但作者、论文、刊期、页码、DOI 可能不存在 | 格式对不等于文献存在 | 不改不删不补，也不“修正”条目；在说明里提醒逐条到知网、万方或 DOI 解析核验 | 强 |
| 精确度漂移：“约 42%”变“超过四成”；“多数”变“全部”；“可能”变“确定” | 失真 | 字面与含义都对照原文 | 强 |

## 何时不动

引文、标题、专名、代码、法规条文、标准定义、外语段落、对话体、承担指代的编号，以及讨论某个词本身的段落（“我最近戒掉了‘赋能’这个词”），里面出现候选信号不算问题。短于两三句的文本不下判断。
